# lava shooter
is a video game where you knock your enemies into lava rather than damaging them

## about
It's my first game made in godot. I usually make games in unity but I wanted a new challenge
It's a top down shooter with a lot of shader effects

## how to play
You can download it from itch.io here: https://cof99.itch.io/lava-shooter but it's only for windows
you'll have to extract the folder then run the exe named "lavaShooter.exe" and you're done :)

# How to work on it
just copy the file named "project.godot" and import it into godot, then copy all other files and drop them into the project you just created
